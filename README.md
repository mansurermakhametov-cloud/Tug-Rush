# Tug Rush: Pirate Seas 🏴‍☠️

3D-игра «Перетягивание каната» в браузере: пиратские команды тянут канат на палубе корабля, а вы решаете, когда рвануть, а когда восстановить силы.

**Играть:** https://mansurermakhametov-cloud.github.io/Tug-Rush/
**Репозиторий:** https://github.com/mansurermakhametov-cloud/Tug-Rush

## Для кого и чем отличается
Для коротких дуэлей с друзьями на одном устройстве или против бота. Отличия от простой игры с двумя кнопками: выносливость, рывки, случайные события на море, ставки на виртуальное золото и магазин косметики для команды.

## Реализованные функции
- Матч до конца: обратный отсчёт 3-2-1, 60 секунд, победа при пересечении линии или по положению флага при окончании времени, реванш. Ввод до старта и после финиша игнорируется.
- Режимы: против бота (3 уровня сложности) и 2 игрока на одном устройстве. Бот подчиняется тем же правилам (выносливость, пауза, рывок), скрытых бонусов у него нет.
- Механика: обычный рывок стоит 5 выносливости, уставший тянет слабее, выносливость восстанавливается только после короткой паузы. «Сурж» — сильный рывок за 40 выносливости с перезарядкой 3 с. Зажатие клавиши ничего не даёт, есть минимальный интервал между действиями.
- Случайность и шанс на камбэк: случайная сила рывка и критические удары; отстающая команда тянет сильнее, а события чаще помогают ей. События: ром, попугай, заморозка, кракен, порыв ветра, пушечный выстрел.
- Ставки: обе стороны ставят одинаково (10/50/100/250), победитель забирает банк. Без денег можно решать арифметические задачи (+20$ за задачу).
- Магазин: скины и снаряжение для команды (только косметика, преимущества за деньги нет), имена капитана и матросов.
- 3D-сцена: корабль с качкой, модели пиратов с деталями, движущееся море, зрители на заднем плане, эффекты (лёд, аура, щупальце, монеты).
- Звук: синтезируется в браузере (Web Audio): звуки рывков и событий, фанфары, аплодисменты и крики при победе. Кнопка отключения звука.
- Управление: P1 — `A` (рывок), `S`/`Space` (сурж); P2 — `J`, `K`; на телефоне — экранные кнопки.
- Сохранение локально (localStorage): деньги, покупки, имена, история матчей.
- Логика игры работает с фиксированным шагом 60 Гц и не зависит от частоты кадров.

## Технологии
HTML, CSS, JavaScript без сборки; [three.js r128](https://threejs.org) (подключается с cdnjs) для 3D; Web Audio API и Web Speech API для звука. Шаблоны и готовые игровые компоненты не использовались, все модели собраны из примитивов three.js.

## AI-инструменты
Код и идея реализованы в диалоге с Claude (Anthropic). Правила, баланс и итоговый код проверены и поняты автором.

## Запуск локально
Скачайте репозиторий и откройте `index.html` в браузере (нужен интернет для загрузки three.js).

## Известные ограничения
- Нет аккаунтов, базы данных и онлайн-мультиплеера: статистика хранится только в браузере.
- Речевой крик «Hooray!» зависит от поддержки синтеза речи в браузере.
- Звук включается только после первого действия игрока (ограничение браузеров).
